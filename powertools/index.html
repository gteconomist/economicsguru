Economics Guru PowerTools

Live charts inside PowerPoint. Insert any chart from this site onto a slide, and refresh every chart in a deck to the latest data with one click — no more cut-and-paste.

Download the add-in file Or use the Deck Refresher →

Install on your Mac (one time, ~1 minute)

Open Terminal (Cmd-Space, type “Terminal”, Enter) and paste these three lines:

cd ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents
mkdir -p wef
curl -o wef/economicsguru-powertools.xml https://economicsguru.com/powertools/manifest.xml

Then quit PowerPoint fully (Cmd-Q) and reopen it. If the Chart Panel button doesn’t appear on the Home tab, open Insert → Add-ins → My Add-ins and pick Economics Guru PowerTools.

This “sideloads” the add-in for your machine only — nothing goes through Microsoft, and there is nothing to pay for or approve.

Using it

  1. Insert a chart: on any slide, open the Chart Panel (Home tab), find your chart, pick range / light-or-dark / series, and click Insert on Current Slide. The chart drops in as a crisp branded image, invisibly tagged with its own recipe.
  2. Before a talk: open the deck, open the Chart Panel, click Refresh All Charts. Every tagged chart is redrawn with the site’s latest data — positions, sizes, and slide layouts untouched.
  3. Hands-free: tick Auto-refresh when this deck opens and save the deck. From then on, opening that file reopens the panel and updates every chart automatically.

No add-in handy? Use the Deck Refresher

On any computer with a browser, drop a .pptx onto the Deck Refresher and download it back with every tagged chart updated. Nothing is uploaded — it all happens in your browser.

Charts update nightly from BLS, BEA, Census, Federal Reserve, and other public sources — see methodology.
